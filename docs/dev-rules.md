# ai-agents-relay-kit: правила разработки

Личная VPN-инфраструктура как код: реестр серверов → генерация конфигов и
подписок (INCY/Happ, полные xray-конфиги, failover-цепочки) → деплой серверов
→ подписочный воркер (CF) → macOS killswitch/самолечение (oxi-vpnks).

## Читать первым

- `docs/failover.md` — архитектура failover-цепочек, инциденты 8.10.
- `docs/incy-desktop.md` — интеграция с INCY Desktop: слои DNS, TUN-ловушки
  (utun244, зомби-xray, порт 10808), залипающее состояние, рецепты
  реинициализации, pf-требования. Обновлять при каждом новом уроке INCY.

## Железные правила

- **Не рестартовать INCY на живой машине без согласия владельца** — блэкаут
  1–2 мин всего, включая provider-путь агента. Правки её preferences/sqlite —
  только при закрытом приложении (живой процесс перезатрёт файл из памяти).
- Клиентские конфиги проверять офлайн-харнесом (`xray run -c` + curl
  `--socks5-hostname 127.0.0.1:10808`); `run -test` — только синтаксис.
- В `dns.servers` генератора — только DoH-по-IP или plain-IP, но НЕ plain-IP
  в проде (INCY берёт их как forwarders TUN-перехвата; валидатор следит).
- Деплой подписок — только вручную `./bin/vpn deploy subs`; откат = git
  revert + deploy.
- git-гейты: identity OXI-717, merge-guard `OXI_ACCEPTOR=1` для своих мержей;
  `vpn uuids fill` перешифровывает secrets.sops.yaml целиком — не пугаться
  диффа, не коммитить чужие правки вслепую.
- oxi-vpnks: `~/bin/oxi-vpnks` — симлинк сюда; смена кода требует
  `sudo launchctl kickstart -k system/com.oxi.vpnks` (команда владельца).
  Единственный pf-менеджер — мы; killswitch INCY выключен в его UI.
- Tailscale: не флипать exit-node живьём (роняет INCY + маршруты 100.64/10).

## Известные чужие баги (обходы в docs/incy-desktop.md)

INCY Desktop 3.8.2: захардкоженный utun244; зомби-ядро xray держит 10808;
TUN-DNS только plain-IP; bypass одного адреса (multi-hop в TUN мёртв);
невосстановление default route; SYSTEM_PROXY через админ-диалог.

## Супервизия и релизы (9.10, вечер)

- **vpn-supervisor** (root-таймер */5 на каждом сервере): gRPC-API xray
  (127.0.0.1:10085) не отвечает 2 прохода → `vpn-helper activate <current>`.
  Ставится вместе с агентом; agent-only путь: `vpn server bootstrap-agent <id>`.
- Флаг `-server` в Go-flag стоит ПЕРЕД подкомандой: `vpn -server kz deploy servers`.
- **KZ: нестандартная топология входа** (при бутстрапе nginx на 443; релиз 30.09
  при этом слушает 0.0.0.0:443). Новый релиз 9.10 ушёл в restart-loop, откачено
  обратно. До разбора топологии KZ не передеплоить; cr>kz-цепочки на svc-ногах
  сломаны (UUID-разъезд) — не чинить вслепую.
- Причина вечера 9.10: svc-UUID реестра разъехались с релизами 30.09 (AM
  чинилось передеплоем; lv/fr перевыпущены). Появление «EOF/timeout на
  цепочке при живых концах» = сначала сравнить UUID реестра с релизом.
- yc-relay disabled в реестре (мёртвый датацентр; блокировал
  `deploy worker-secrets` навсегда).
